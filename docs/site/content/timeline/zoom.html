TimelineZoom

import { TimelineZoom } from '@karoly-pfaff/audio-controls-react/timeline'

A compact toolbar with zoom-out, a native range input, zoom-in and “Fit song”. Use the viewport's controlled zoom pair in a full composition.

Props

zoom ranges from 1 to MAX_TIMELINE_ZOOM (32). The range input uses integer steps. Fit resets to 1; the boundary buttons disable at their corresponding limits.

The standalone demo shows the toolbar's state only. To scale and anchor actual content, pass view.zoom and view.changeZoom from TimelineViewport. The viewport owns the scrolling mechanics.
