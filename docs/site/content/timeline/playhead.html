15 / TIMELINE

TimelinePlayhead

import { TimelinePlayhead } from '@karoly-pfaff/audio-controls/timeline'

A controlled vertical position indicator. It maps source seconds to a percentage of the full timeline surface.

Props

The visual position is clamped to 0–100%. With nonpositive duration, it stays at the start. This visual guard does not validate the host's full timeline model.

Its parent must be positioned, usually TimelineViewport's content element. Base CSS places the line below the 24px ruler and extends it to the bottom of the lane stack.

The playhead is aria-hidden and ignores pointer events. It does not advance itself, request frames, seek the audio or scroll the viewport. Supply your playback position or deterministic export time from the host.
