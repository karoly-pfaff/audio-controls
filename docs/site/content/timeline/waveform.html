13 / TIMELINE

TimelineWaveform

import { TimelineWaveform } from '@karoly-pfaff/audio-controls-react/timeline'

An SVG envelope of prepared minimum/maximum peaks. It reduces the visible source window while preserving the full-song coordinate system.

Props

  • onSeek(seconds) reports source seconds, including when the waveform is zoomed and scrolled.
  • Use the actual view.viewport in a viewport composition. The fixed pixel window in this standalone example is only for its unzoomed full-source display.
  • Empty peaks show an explicit “Waveform unavailable” status. The component never invents audio data.
  • The SVG has role="img". Pointer seeking is an enhancement; a host-owned range input provides a keyboard alternative.
  • Color comes from --acr-waveform, then --studio-muted, then currentColor. A custom class replaces acr-timeline-waveform.

Peaks must have equal-length arrays of finite extrema on a uniform time axis. Validate persisted or external peaks before passing them into the component. It does not decode, analyze or resample an audio file.
