11 / TIMELINE

TimelineViewport

import { TimelineViewport } from '@karoly-pfaff/audio-controls/timeline'

The scrolling and measurement owner for a complete timeline. Render callbacks receive a single TimelineView shared by the toolbar and the full-width content surface.

Props

view.zoom is the current multiplier; view.changeZoom updates it; view.viewport contains measured pixel widths and horizontal scroll offset. Pass that window directly to TimelineWaveform.

Changing zoom anchors the current source position within the view where possible. The viewport does not play audio or automatically follow a moving playhead. Host playback state and any follow policy remain separate.

The scroll container is keyboard-focusable and resize-aware. The base stylesheet establishes horizontal overflow and relative content positioning. Custom scrollClassName and contentClassName replace the defaults; keep equivalent positioning/overflow rules or include the original class in your value.

Keep empty states outside the timeline.

Use a finite, positive source duration when rendering a ruler. Until audio metadata is ready, show a loading or unavailable state instead of passing zero duration through the full composition.
