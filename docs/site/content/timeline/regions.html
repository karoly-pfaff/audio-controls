TimelineRegionLane

import { TimelineRegionLane } from '@karoly-pfaff/audio-controls-react/timeline'

A lane of native buttons placed at source-time regions. Use it for song sections, annotated spans or lightweight chapter navigation.

Props

A region has a stable id, source-second start and end, a visible label and optional title. Clicking or keyboard-activating a button calls onSeek(region.start).

The host validates 0 ≤ start < end ≤ durationSeconds, ordering, overlap policy and stable identity. This view does not resize or reorder regions, manage selection or validate a saved project schema.

Regions use percentage positioning across the full source. Place them inside the same TimelineViewport content as the waveform and ruler. Long labels are clipped by the base styles; provide concise names and supplemental titles when appropriate.
