07 / AUDIO CONTROLS

TransportControls

import { TransportControls } from '@karoly-pfaff/audio-controls-react'

A transport group with restart, back, play/pause, stop and forward actions. Connect its callbacks to your existing player.

Props

Every prop is required, including the booleans. disabled disables the group; playable determines whether playback can start. playing selects the play or pause action.

The host decides jump length, stop semantics and end-of-track behavior. The demo jumps by 10 seconds and clamps to a 120-second source. Play changes state only; the example does not advance a clock or emit sound.

Shortcut hints in tooltips do not install listeners. Bind any host shortcuts explicitly. Keep the built-in jump callbacks at five seconds to match their accessible labels; use TransportButton for differently named jump actions.

TransportButton

import { TransportButton } from '@karoly-pfaff/audio-controls-react'

Build a custom transport layout from one accessible action at a time.

Props

icon is one of restart, back, play, pause, stop or forward. The SVG is decorative; the required label names the button.

active is a visual class hook, not an aria-pressed state. Use ToggleButton for a persistent toggle. Keep ordinary transport actions as buttons.
