05 / AUDIO CONTROLS

Knob

import { Knob } from '@karoly-pfaff/audio-controls'

A compact SVG control for pan and other bounded values. Pointer dragging, direct ring selection and keyboard adjustment all feed the same controlled callback.

Props

  • Defaults: min=-1, max=1, step=0.01, unit="L/R". It has the Slider contract except showLabel.
  • Drag vertically to adjust. A pointer press outside the center dead zone first selects a value on the arc.
  • ↑/→ increase; ↓/← decrease; Home/End select range ends.
  • Double-click resets to zero, clamped to the supplied range. It does not choose the midpoint of an arbitrary range.
  • The SVG exposes role="slider" and a value text. Disabled knobs cannot be adjusted and leave the tab order.

The SVG has a 32×32 view box. A built-in theme displays it at 40px using --acr-knob-size. Scale it with host CSS while retaining its view box. The example also includes a pan Slider bound to the same state.
