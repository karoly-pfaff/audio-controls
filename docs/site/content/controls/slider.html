04 / AUDIO CONTROLS

Slider

import { Slider } from '@karoly-pfaff/audio-controls'

A labeled native range input with controlled numeric values and a formatted readout. Use it for linear gain, normalized mix values or explicit pan ranges.

Props

Behavior & integration

  • Defaults: min=0, max=1, step=0.01. Supply a matching finite value within your range.
  • onChange receives a number, never a DOM event. Update the host state and audio parameter there.
  • unit="dB" expects linear gain; 1 displays 0.0 dB and 0 displays −∞. Negative linear gain is not a valid input for this display mode.
  • showLabel={false} hides only the visible label text. The formatted value and accessible name remain.
  • Set accessibleLabel when multiple controls would otherwise have the same name.

The first two sliders in this example share one value to demonstrate the difference between a linear value and its display formatting. The third demonstrates the disabled state.
