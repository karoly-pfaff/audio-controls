06 / AUDIO CONTROLS

ToggleButton

import { ToggleButton } from '@karoly-pfaff/audio-controls'

A native button with a controlled pressed state. Use the variant class to express mute, solo or loop intent without coupling it to your audio model.

Props

onClick takes no arguments. Flip the appropriate host value yourself; the button does not infer mute/solo dependencies. active drives aria-pressed and the active class.

label accepts React content. Give icon-only labels an ariaLabel. The optional title is supplemental text, not a substitute for an accessible name.

Variants are default, mute, solo and loop. Their names supply class hooks; the optional base stylesheet deliberately leaves semantic color choices to the host theme.
