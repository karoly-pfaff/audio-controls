09 / AUDIO CONTROLS

StereoMeter

import { StereoMeter } from '@karoly-pfaff/audio-controls'

A two-row display of normalized left/right levels with attack and decay smoothing. It reads your callback on animation frames and updates its bars without rerendering the application for every sample.

Props

readLevels() returns { left, right } with finite display levels between 0 and 1. The meter clamps finite levels to this range. It performs no RMS, FFT or peak detection.

When playback stops, return zero levels so the display can decay and stop requesting frames. Keep the callback identity stable with useCallback where appropriate. The meter cancels its own frame callback when unmounted or rebound.

Provide a textual alternative when needed.

The rapidly changing bars are aria-hidden. If level information is essential, provide a separate restrained textual summary in your host instead of announcing every animation frame.
