10 / AUDIO CONTROLS

CanvasWaveform

import { CanvasWaveform } from '@karoly-pfaff/audio-controls-react'

A cached canvas waveform for compact players and track lanes. It accepts prepared extrema and a normalized playhead, with optional controlled seeking.

Props

  • Default intrinsic size is 800×48 pixels; default waveform color is #00e5ff.
  • peaks=null represents unavailable audio. It does not synthesize waveform data.
  • playhead and onSeek use a 0–1 ratio. tickDurationSeconds supplies source duration for 30-second tick marks.
  • Interactive behavior defaults on when both peaks and onSeek are present. Set interactive={false} for a purely visual view.
  • Keyboard arrows adjust the ratio by 0.01, Home selects 0 and End selects 1. The interactive canvas exposes slider semantics.
  • handlers can replace pointer/key behavior for host-owned selection and annotations. A supplied handler for an event takes precedence; retain accessible keyboard seeking in the host.

The cached background depends on peak identity, dimensions, color and tick configuration. A new playhead draws over the cached waveform. Supply stable immutable peak arrays, and set intrinsic dimensions deliberately for your host's sizing strategy.

The built-in themes use a dark canvas plot surface in both palettes for white overlay contrast. Set color to a concrete six-digit hex waveform color; see the canvas theme adapter for a controlled palette example.

This component does not accept selection/marker props; compose those overlays in your host. The SVG timeline component uses seconds instead of ratios.
