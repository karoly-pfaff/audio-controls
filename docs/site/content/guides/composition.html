03 / COMPOSITION

A complete source-time timeline

Start here to see the timeline pieces working together. The viewport shares its zoom, zoom action and measured window with every lane. All seek callbacks update the same position in seconds.

Composition recipe

  1. Keep one positionSeconds in the host.
  2. Pass duration and position into TimelineViewport.
  3. Use its toolbar(view) for TimelineZoom and a keyboard scrubber.
  4. Place the ruler, waveform, regions and playhead inside children(view).
  5. Pass the measured view.viewport to the waveform and the same duration to every lane.
One axis, even at 32×.

A click on a waveform at 75% of the full content means 90 seconds in a 120-second track. Do not multiply the callback by zoom or add scroll position again.

The visible waveform is reduced from prepared peaks with a bounded offscreen margin. Region labels are ordinary buttons. The playhead is a visual layer; the native range input in the toolbar provides a keyboard-operable source-time alternative.

The example includes multiple source files and a deterministic synthetic fixture. Copy the companion files shown with the example, preserving their relative imports. No music file is required.
