Customize your theme

1. Override a named palette

Load your stylesheet after the package CSS. Attach the class and theme attribute to the same container. Override semantic tokens instead of copying component selectors.

Brand palette · host stylesheet 
.brand-controls[data-acr-theme] {
  --acr-accent: #0f766e;
  --acr-on-accent: #ffffff;
  --acr-focus: #0f766e;
  --acr-radius: 10px;
  --acr-gap: 12px;
}

.brand-controls[data-acr-theme='light'] { --acr-waveform: #0f766e; }
.brand-controls[data-acr-theme='dark'] {
  --acr-accent: #5eead4;
  --acr-on-accent: #042f2e;
  --acr-focus: #99f6e4;
  --acr-waveform: #5eead4;
}
React container 
<div className="brand-controls" data-acr-theme={theme}>
  <Slider label="Mix" value={mix} onChange={setMix} />
</div>

2. Change density or one component

Local sizing overrides 
.compact-controls[data-acr-theme] {
  --acr-control-height: 28px;
  --acr-gap: 4px;
  --acr-knob-size: 32px;
  --acr-meter-height: 6px;
}

/* Same theme, different local control scale. */
.brand-controls .large-pan { --acr-knob-size: 56px; }

/* Host-specific layout stays in your stylesheet. */
.brand-controls .acr-stereo-meter .stereo-meter-track { width: 180px; }

Pass className="large-pan" to Knob. It appends that class to its base wrapper, so the local token affects only that control. Keep touch targets comfortable and preserve visible focus when changing density.

3. Bridge the canvas color explicitly

--acr-waveform controls the SVG waveform. CanvasWaveform rasterizes its color prop and caches the background; pass a concrete color from your application palette to redraw it when that palette changes. A literal var(--acr-waveform) is not a canvas color value.

Canvas palette adapter 
const palette = {
  light: { canvasWaveform: '#a78bfa' },
  dark: { canvasWaveform: '#b19aee' },
};

<CanvasWaveform
  peaks={peaks}
  color={palette[theme].canvasWaveform}
  playhead={positionRatio}
  onSeek={seekRatio}
/>

Use a six-digit hex #RRGGBB waveform color: the renderer appends alpha bytes for its envelope. Keep the peak identity stable; changing color updates the cached paint without decoding audio again. The live comparison's useThemeSettings hook demonstrates typed CSS properties and the matching canvas prop.

4. Keep the positioning contract

Slider and Knob append className to their base classes. Timeline class props replace their defaults. To retain package layout and theme rules, include both names: className="acr-timeline-waveform my-waveform". Keep the viewport's relative content positioning and horizontal overflow.

Legacy Lab hooks remain available. Scope new overrides to your container and the owning acr- class. The package does not theme unrelated native fields; style your host toolbar and form controls explicitly.

5. Follow a system preference in the host

Read matchMedia('(prefers-color-scheme: dark)') in your browser lifecycle if you want a system default, then select light or dark on your container. The host owns preference persistence, change listeners and cleanup. Keep server/client initial markup consistent.

Check custom palettes in forced colors and with keyboard focus. The built-in themes use system button/highlight colors in forced-colors mode; they introduce no transition animation or global preference listeners.

Native controls and SVG geometry use system colors in this mode. The canvas retains its raster plot colors and dark surface so its existing white position/tick overlays remain visible; provide host-level textual position controls alongside visual waveforms.
