01 / GETTING STARTED

Installation & setup

Install the scoped package from GitHub Packages into your React application. Authenticate with a personal access token with read:packages access, including for public packages. Keep the token in your user npm configuration rather than committed project files.

Terminal · your React application 
npm login --scope=@karoly-pfaff --auth-type=legacy --registry=https://npm.pkg.github.com
npm config set @karoly-pfaff:registry=https://npm.pkg.github.com --location=project
npm install --save-exact @karoly-pfaff/audio-controls-react@0.1.0

The package supports react ^18.3.1 || ^19.0.0. Your host supplies React and its renderer. Use a bundler that understands ESM, package exports and CSS imports.

Minimal controlled React component 
import { useState } from 'react';
import type { ReactElement } from 'react';
import { Slider } from '@karoly-pfaff/audio-controls-react';
import '@karoly-pfaff/audio-controls-react/styles.css';

export function OutputGain(): ReactElement {
  const [gain, setGain] = useState(0.75);
  return (
    <div data-acr-theme="light">
      <Slider label="Output gain" value={gain} unit="dB" onChange={setGain} />
    </div>
  );
}
Bring your own state.

onChange reports a candidate value. Update the supplied value to reflect it. The package does not create an audio context or change a gain node for you.

With an SSR framework, put interactive examples behind its client boundary. Package imports are safe without browser audio globals; canvas painting and viewport measurement happen when mounted in a browser.

02 / FOUNDATIONS

Controlled values & units

Keep units explicit at the host boundary. The controls do not infer whether a number means seconds, gain or a normalized position.

Value Unit / range Meaning
Gain slider value Linear amplitude; default range 0–1 unit="dB" formats 20 × log10(value). It still emits linear gain.
Pan knob value −1…1 by default −1 is left, 0 is center, 1 is right. Default unit is L/R.
Canvas playhead / onSeek Position ratio 0–1 Convert with seconds = ratio * durationSeconds.
Timeline positions and regions Source seconds Use the complete source timeline, including when zoomed or scrolled.
Meter levels Normalized display levels 0–1 The host computes them; this is not a dBFS analyzer.
Timeline zoom 1…32 multiplier 1 fits the full source. Zoom is independent of audio playback rate.
Formatting is intentionally narrow.

dB and L/R have special formatting. Other unit strings display a rounded percentage; they are not appended as arbitrary units. Use a native range input and your own label for a seconds scrubber.

Waveform peaks are prepared visual extrema, not a decoded track or analyzer result. Keep peak arrays stable between renders to preserve paint caching. The host owns input validation, decoding, playback, subscriptions, persistence and export clocks.
