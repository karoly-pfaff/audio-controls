Integrate a project timeline

Translate your project model into generic regions and prepared peaks at the host boundary. Keep scene cards, selection, thumbnails, editing commands and persistence in the application.

Keep preview and export in sync

Controls display source time; they do not own an export scheduler. During export, derive time from frame index and frame rate in your renderer. Do not accumulate animation-loop deltas or use documentation meter time as a source clock.

Server rendering

Importing the package requires no Web Audio globals. Render static controls or initial markup on the server, then mount interactive components on the client. ResizeObserver, canvas contexts and animation frames belong to the browser lifecycle.

Source imports are not the integration contract.

Install the tarball or a deliberately versioned package. Import documented entries rather than sibling sources, internal build paths or private hooks.

23 / SUPPORT

Troubleshooting

Symptom Check
The slider snaps back Update its controlled value in onChange. A callback alone does not change the next rendered value.
Gain displays NaN dB formatting expects nonnegative linear gain, not already-converted decibels.
Timeline lanes stack incorrectly Import base CSS or preserve relative positioning, lane heights and horizontal overflow in custom classes.
Seek jumps after zooming Timeline callbacks already report full-source seconds. Do not reapply scroll offset or zoom. Canvas reports a ratio instead.
Waveform is empty or incorrect Validate equal-length finite peak arrays. Empty SVG peaks intentionally show unavailable. For right-only content, use all-channels aggregation.
Waveform repaint is expensive Keep peak identity stable; reduce once per decoded track/resolution rather than on each playhead update.
Meter keeps animating while paused Return zero levels when stopped; playing=false allows the smoothing tail to decay but does not silence a nonzero callback.
Copy is unavailable from a local file The button selects code as a fallback; press Ctrl/Cmd+C. Browser clipboard permissions vary by origin.
An old local package is still installed Rebuild/repack, replace the local artifact and deliberately refresh the consumer lockfile/install. Do not overwrite a published version.
24 / DEVELOPMENT

Development & quality

Use Node 24 and npm 11. The repository has strict typed ESLint, SonarJS, component/effect boundaries, Knip, zero-duplication jscpd and a separate directory for each control.

The library gate requires 100% lines, statements, functions and branches per executable production file, including unimported library sources. Documentation examples are typechecked separately and use the built public package entries. They are not part of the published library runtime.
