Light & dark themes

Import the package stylesheet once and select a built-in theme on a container. The theme covers labels, knobs, buttons, focus rings, meters and timeline lanes. Controls inherit the nearest theme's tokens.

Choose a theme per container 
import '@karoly-pfaff/audio-controls/styles.css';

<div data-acr-theme="light">{/* your audio controls */}</div>
<div data-acr-theme="dark">{/* another independent group */}</div>

Use the controls below to compare both palettes and customize their accent and corner radius independently. Each card uses the shipped stylesheet; its settings update CSS custom properties on that card.

Switch themes in React

Controlled theme selection 
import { useState } from 'react';
import type { ReactElement } from 'react';
import { Slider } from '@karoly-pfaff/audio-controls';
import '@karoly-pfaff/audio-controls/styles.css';

export function ThemedGain(): ReactElement {
  const [theme, setTheme] = useState<'light' | 'dark'>('light');
  const [gain, setGain] = useState(0.75);
  return (
    <div data-acr-theme={theme}>
      <button type="button" onClick={() => setTheme(theme === 'light' ? 'dark' : 'light')}>
        Switch theme
      </button>
      <Slider label="Gain" value={gain} onChange={setGain} unit="dB" />
    </div>
  );
}

The host owns selection, persistence and any system-preference listener. For SSR, choose a deterministic initial theme and synchronize your saved preference on the client. This stylesheet does not read storage or install listeners.

Scope and nesting

Themes are selected with data-acr-theme="light" or "dark"; put the attribute on an ancestor of the controls. A nested theme container starts its own palette and sizing defaults. Add custom overrides to that same container when you want them to survive the reset.

The package styles do not reset the body or unconnected form fields. Add layout, padding and styles for your application's own buttons separately. Controls outside a theme container retain the base stylesheet behavior and host styling hooks.

The top-bar theme button switches the documentation shell and ordinary live previews. The two comparison cards above remain independently scoped, including when their parent preview changes theme.
