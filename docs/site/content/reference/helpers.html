17 / PURE HELPERS

Waveform peak reduction

import { waveformPeaksFromChannels } from '@karoly-pfaff/audio-controls'

Convert channel sample arrays into visual minimum/maximum columns. This is a display helper, separate from decoding, beat detection and audio analysis.

Prepared peaks from host-owned decoded audio 
const channels = Array.from(
  { length: audioBuffer.numberOfChannels },
  (_, channel) => audioBuffer.getChannelData(channel),
);
const peaks = waveformPeaksFromChannels(channels, {
  columns: 800,
  aggregation: 'all-channels',
});
Option Contract
channels Readonly list of Float32Array channels. Supply finite normalized samples and equal-length decoded channels. Inputs are not mutated.
columns Integer from 1 to 4096. Invalid resolution throws RangeError.
first-channel Uses the first channel with legacy ceil-stride buckets. Preserves Audio Layer Lab's display policy.
all-channels Uses proportional buckets and extrema across channels, preserving right-only and anti-phase events. Preserves Audio Signal Lab's display policy.

Extrema are aggregated, not averaged. Opposite-phase channels therefore do not cancel visually. An empty channel list produces zero extrema. Cache the result by audio identity and display resolution instead of reducing samples on each playback tick.

Timeline geometry helpers

import { … } from '@karoly-pfaff/audio-controls/timeline'

Use these functions when building host-specific lanes while retaining the same source-time geometry as the ready-made controls.

Export Behavior & limits
MAX_TIMELINE_ZOOM 32. Shared upper zoom bound.
clampTimelineZoom(zoom) Clamps finite numbers to 1–32. Throws RangeError for nonfinite values.
timelineTicks(duration, zoom) Returns readonly { seconds, percent, label } ticks. Duration must be finite and positive or it throws RangeError.
formatTimelineTime(seconds, fractional) Formats clock time; optional centiseconds. Intended for nonnegative source positions.
timelineRegionStyle(region, duration) Returns CSS percentage left/width. The host validates region boundaries and positive duration.
isTimelineRegionVisible(region, viewport, duration) Tests pixel overlap with a 64px offscreen margin. Does not sort, clip or mutate regions.
waveformColumns(peaks, columns = 512) Aggregates extrema into at most the requested number of columns. Resolution must be an integer from 1 to 2048 or it throws Error.
waveformWindow(peaks, viewport) Returns offset, length, total and reduced visible columns with 64px overscan. Nonpositive content width selects the full source.
waveformOutline(wave) Creates a closed SVG path from a waveformWindow result. No columns produces an empty string.
Source seconds → lane positions 
import {
  timelineRegionStyle, isTimelineRegionVisible, formatTimelineTime,
} from '@karoly-pfaff/audio-controls/timeline';

const region = { start: 24, end: 60 };
const style = timelineRegionStyle(region, 120); // { left: '20%', width: '30%' }
const label = formatTimelineTime(42.25, true); // '00:42.25'
const visible = isTimelineRegionVisible(region, {
  width: 800, scrollLeft: 0, contentWidth: 1600,
}, 120);
Display math is not domain validation.

Validate external durations, region arrays and saved documents at your host boundary. Helpers with no stated validation contract should receive already-validated input.
