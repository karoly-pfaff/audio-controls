Theme token reference

Override these CSS custom properties on a theme container or a more specific control scope. Palette selectors use zero specificity, so your named class can override them without !important.

Token Light Dark Use
--acr-surface #ffffff #1a1e2b Theme container and timeline content
--acr-surface-raised #f2f4f8 #252c3e Buttons and SVG waveform surface
--acr-text #202537 #ecedf5 Primary labels, icons and knob readout
--acr-muted #5f687c #a5b1c9 Secondary values, ruler and meter labels
--acr-border #7b879d #71809b Button/viewport borders, knob track, meter background
--acr-accent #6845d6 #b49bff Native range accents, active buttons, playhead and hover
--acr-on-accent #ffffff #19122e Active-button text/icons
--acr-focus #6845d6 #ccbaff Visible keyboard focus
--acr-waveform #7653ce #b19aee SVG timeline waveform fill
--acr-meter #147d68 #68d6b4 Normalized level bar fill
--acr-mute #a92e3c #ffb0b5 Active mute color
--acr-solo #76550a #f4d98b Active solo color
--acr-canvas-surface #111827 Dark raster plot surface in both themes
--acr-radius 6px Buttons, viewport and plot corner radius
--acr-control-height 32px Button minimum height and region lane height
--acr-gap 8px Transport and zoom spacing
--acr-knob-size 40px Themed knob width and height
--acr-meter-height 8px Meter track height

Use CSS lengths for sizing tokens and valid CSS colors for palette tokens. Keep foreground/background pairs readable, including active, hover, disabled and focus states. The live demo computes black/white active text for its selected accent; your host owns that policy for custom palettes.

Canvas plot pixels are controlled by React props, not SVG/CSS fill. Its default dark plot surface keeps the existing white playhead and source-time ticks visible in both themes. Keep a contrasting raster waveform color and consider those fixed overlays when changing the canvas surface.
