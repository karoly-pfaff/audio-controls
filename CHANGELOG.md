# Changelog

## 0.1.0

Initial version of @karoly-pfaff/audio-controls, licensed under MIT.

- Thirteen controlled React audio/timeline controls, with React 18/19 peer support.
- Source-time viewport, zoom, ruler, regions, waveform reduction and playhead composition.
- Scoped light/dark styles with semantic CSS tokens and independent theme groups.
- Standalone offline HTML documentation with sixteen interactive examples.
- Strict quality gates and per-file 100% production coverage.
